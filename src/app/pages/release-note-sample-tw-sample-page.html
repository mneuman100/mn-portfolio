Release Note Type: Before/After · Field change

Manage new rounding options on the billing profile

Related ticket number(s)

ORDEV-XXXX

Previously

On the billing profile, when you selected the field: Round line items, this rounded to the nearest dollar.

Now

You can now round line items for premiums using one of three options.

On the billing profile, when you select the field: Round line items, the following options are now available:

  • Round to the Nearest Dollar: To round $.50 and up to $1.00, and $.49 and lower to $0.00. Any remainder of the premium, positive or negative, is added to the first or last installment.

Round to the Nearest Dollar is how this field worked previously, and is the default option.

  • Always Round Down: To round any amount $.99 or lower down. For example, $2.87 will become $2.00. Any remainder of the premium, positive or negative, is added to the first or last installment based on the settings.

  • Always Round Up: To round any amount $.01 or higher up. For example, $2.07 will become $3.00. Any remainder of the premium, positive or negative, is added to the first or last installment based on the settings.

Release Note Type: Bug fix · Behavior correction

Pay As You Go (PAYG) invoices are no longer canceled when the PAYG policy is canceled

Related ticket number(s)

ORDEV-XXXX

Previously

When a policy was canceled, if the credit from the cancellation paid off the invoice, the invoice would be set to a canceled status. This applied to PAYG policies as well.

Now

Since PAYG invoices may still generate a premium after a PAYG policy is canceled, the system no longer sets PAYG invoices to the canceled status, even if the cancellation credit pays off the invoice. This lets the insured still report payroll that could make more premium due than the credit would have paid off.

Release Note Type: Field Reference

Update value collection assignment status to pending using a value collection email event

Related ticket number(s)

ORDEV-XXXX

Now

You can now use a value collection email event to update assignment statuses from "Assigned" to "Pending", which indicates that an email has been sent to the assignee.

New fields

New fields on the New Value Collection Event screen.

Automatically update Status from Assigned to Pending

Available only when Assigned is selected in Assignment Status/ Status.

Determines if "Assigned" assignments will be set to "Pending" after the event is triggered.

  • When this event is triggered, to automatically update "Assigned" assignments to a status of "Pending", select this option.

  • When this event is triggered, to not change the status of "Assigned" assignments, clear this option.

The "Pending" status indicates that an email has been sent to the assignee.
