Importing migration files

Download and import migration files or configuration templates to another environment.

> Learn how to create migration exports

> Learn how to manage migration exports

> Learn more about configuration migration

To download a migration file

  1. From the main menu, select Admin.

  2. In the Administration section, select Configuration Migrations.

  3. Select Go to Exports.

  4. Select the migration export you want to download.

  5. Select Download Migration File.

  6. Select OK.
    The migration file is downloaded.

If the system finds a problem when building the download file, a message is displayed with instructions on how to continue downloading

To import a migration file

Before you can import a custom configuration package to your database, you must download the migration file for the package you want to import.
> Learn how to download a migration file

  1. From the main menu, select Admin.

  2. In the Administration section, select Configuration Migrations.

  3. Select Start New Import.

  4. Select the migration file you want to import.

  5. Select Start Migration Import.

  6. On the Migration Imports screen, select Test Import.
    > Get detailed information about this screen

  7. Resolve errors and field aliases, if required.
    > Learn more about correcting errors on imports

  8. Once there are no errors, field aliases, or changes to review, select Apply Migration Changes to complete the installation and update the database.

To compare and merge migration files during import

Before you can import a custom configuration package to your database, you must download the migration file for the package you want to import.
> Learn how to download a migration file

  1. From the main menu, select Admin.

  2. In the Administration section, select Configuration Migrations.

  3. Select Start New Import.

  4. Select the migration file you want to import.

  5. Select Start Migration Import.

  6. On the Migration Imports screen, select Test Import.
    > Get detailed information about this screen

  7. Resolve errors and field aliases, if required.
    > Learn more about correcting errors on imports

  8. Select Compare/Merge.
    A screen displays listing all the configurations being updated.

  1. Select the configuration you want to compare and merge.
    A screen displays showing the current data in the source file being imported, an Editor area, and data in the destination.

  1. To make changes, in the Editor area, enter the changes and select Apply.
    The system saves the new value in the destination regardless of what is in the importing file.

To push a migration export to another environment

Push a custom export directly to another database, instead of downloading and manually importing migration files.

Before you can push an export to another environment, the Service team must create a logical environment for you.

Before you can push an export to another environment, you must create a logical environment.

Logical environments are domains you can use to define the environments to which you can push your exports.

> Learn how to create logical environments

> Learn how to manage logical environments

  1. From the main menu, select Admin.

  2. In the Administration section, select Configuration Migrations.

  3. Select Go to Exports.

  4. Select the migration export you want to push to another environment.

  5. Select Push Migration.

  6. Provide the relevant values, for example, the environment to which you want to push the export.
    > Get detailed information about this screen

  7. Select Save Migration Schedule.

To import a configuration template from the configuration repository

A configuration template is a default configuration package that you can import into your database.

> Learn how to install and test a configuration template in your database

  1. From the main menu, select Admin.

  2. In the Administration section, select Configuration Migrations.

  3. Select More > Configuration Template Repository.

  4. Select Install for the configuration template you want to import.

  5. Resolve errors and field aliases, if required.
    > Learn more about correcting errors

  6. Once there are no errors, field aliases, or changes to review, select Apply Migration Changes to complete the installation and update the database.
