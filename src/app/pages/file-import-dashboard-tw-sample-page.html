File Import Dashboard

Your dashboard consists of three main sections. We will go over the sections in the order in which your file will travel.

Start a New Import

This is where you will upload your data file to our database. Once your data file is uploaded to our database, the file will also be moved to the Incomplete Imports section of Your Dashboard.

  • Select Files Button: Select this button to start the upload process of your data file that contains all of the information about a loan set

Incomplete Imports

This is where all files reside after they have been uploaded to our database but have not yet completed the Data Importer processes. These include: Mappings, Translations, Calculations, Pool Preferences and Assumptions. Once these processes are complete, the file then moves to the Ready To Review section of Your Dashboard where you can make changes or print the results.

  • Arrow: This arrow will be Gray while a file is being uploaded, and Green when it is finished. This button is used to access the Data Importer.

  • (i): Use the Info button to see detailed information about your Data File.

  • (X): Use the Delete button to delete the imported file from the system.

  • (R): Use the Refresh button to refresh the information being displayed in the table.

Ready To Review

This section shows all files that have completed the Data Importer process. Here, you can change values on the Pool Preferences and Assumptions pages which will impact the value, positive or negative, of the data. From the final summary page you can then sign off on your decisions.

  • Arrow: This button is used to access the Data Importer, starting at the Pool Preferences page.

  • Reports: This section allows you to print out the results of the Analysis.

  • Export:

    • Excel- This option allows you to export the results of the Analysis into an Excel Spreadsheet.

    • Intex- This option allows you to export the results of the Analysis into an Intex compatible file.

  • (R): Use the Refresh button to refresh the information being displayed in the table.

Before you Import your File

Please review these requirements needed to ensure a successful import:

  1. The system can only import files that are in the following formats: Excel (both .xls and .xlsx), and CSV formatted files.

  2. The system can only import data located on the first tab of a spreadsheet. If you have data on other tabs, they must be moved to the first tab, or separated out into their own files.

Importing a File

The first step in using our system is to upload your data file that contains all of the information about a loan set.

  1. Log into Analysis Suite.

  2. From Your Dashboard, click the Select Files button in the Start a New import section. This will access the Open dialog box.

  3. Select the data file you want to upload, then click the Open button. The system will now begin uploading the file to our server.

  4. Once the file has been successfully uploaded, it is moved to the Incomplete Imports section on Your Dashboard. From here, the system will begin uploading the data into our system.

    • Uploading data from your file may take several minutes.

  1. When the system is finished, the arrow will turn green.

Mappings

Now that you have uploaded your file to the system, the next step is to map the custom fields in your file to the corresponding fields in Analysis Suite. This will enable Analysis Suite to analyze your data correctly.

Accessing the Mapping Page

  1. Log into Analysis Suite.

  2. From Your Dashboard, find the file you want to work with from the Incomplete Imports section.

    • If your file is not there, first import it through the Start A New Import section.

  1. Click the Green arrow button to the right of your file to enter the Data Importer.

    • If the arrow button is grey, the system is still uploading the file. When complete, the arrow will turn green and you can continue.

Mapping your Data Fields to the System

On the Mappings Page, you will manually map the custom fields in your file to the corresponding fields in Analysis Suite. Even though you are only required to map the 10 Critical Fields, we HIGHLY recommend that you map as many fields as possible to get the most accurate results from our system.

Note:When you first enter this page, a standard Template "Standard Mapping" has already been selected for you in the "Template" drop down list. This template attempts to automatically match as many fields as possible for you. Once you make a change in the workspace, you will be asked to create your own customized template.

  1. In the Mappings Workspace, working from left to right, look at Field name in the Our Field Name section of the first row.

  2. Using the table below, decide which of your columns (in your data file) match the description for Our Field Name.

    • You may need to review your data file from your computer to determine the best match.

  1. Once you have found the matching column from your data file, select that column name from the Your Column Name drop down list, on the right, in the same row (To access the drop down list, click the field to turn it green, then click again to open the drop down list containing your list of column names.)

    • If there is already a column name in this field, verify it is correct, or select the correct one from the drop down list.

    • Advanced Tip: To find your field faster, once the drop down list is showing, type a portion of the field name. The drop down list will then automatically limit your choices to only those that contain your typed text.

  1. Now that you have made a change to the standard Template, the Copy Existing Mapping Template dialog box will be displayed.

    • Select a new name for your Template, and add an optional description. Once saved, your new template will be added to the Template Drop down list on the Mappings Workspace where it can be reused.

  2. Now that you have saved your custom Template, continue down each row until all fields are correctly mapped. We HIGHLY recommend that you map as many fields as possible to get the most accurate results from our system.

    • Advanced Tip: While you are working, review the Mapping Statistics section, on the right, to check your progress.

  1. When you are done mapping the fields, click the Next button to continue to the Translations Page.

    • The Next button will be grayed out and unusable until you have mapped all 10 Critical Fields.

  1. After clicking Next, the Verify Information page is displayed.

  2. Make any needed changes, then click Save and Continue.

Translations

Now that you have mapped your columns to our system, the next step is to verify that your data, from certain fields, will be translated properly into the system. This is a very important step that allows Analysis Suite to analyze your data correctly.

Accessing the Translations Page

  1. Log into Analysis Suite.

  2. From Your Dashboard, find the file you want to work with from the Incomplete Imports section.

  3. Click the Green arrow button to the right of your file to enter the Data Importer.

  4. You are now on the Mappings page. If all the information is correct, click Next.

  5. After clicking Next, the Verify Information page is displayed.

  6. On this page make any needed changes, then click Save and Continue.

  7. You are now at the Translations Page.

Translating Our Fields to Your Data

On the Translations Page, you will focus on certain fields from your data file (determined from the Mappings page). From here, you will manually link the data in our fields to the data in your data file's columns. As with Mapping, we HIGHLY recommend that you translate as many fields as possible to get the most accurate results from our system.

Note:When you first enter this page, a standard Template, "Standard Translation", has already been selected for you in the "Template" drop down list. This template attempts to automatically match as many fields as possible for you. Once you make a change in the workspace, you will be asked to create your own customized template.

  1. In the Translations Workspace, working from left to right, look at the first Field name, bolded. This is the first field that needs translation. Under this field is a section that shows several rows, one for each of your distinct data items in this field.

  2. Focusing just on the field's section, you will see the following columns:

    • Field Name, shows the field name again.

    • Your Value, shows each of your distinct data items in this field

    • Our Value, shows the detailed information that we will translate your data into.

  3. Now, determine if your data in the Your Value column matches what may have been automatically selected in the Our Value column.

  4. Change any selections in the Our Value column using the drop down list.

    • Once you make your first change, the Copy Existing Mapping Template dialog box will be displayed.

    • Select a new name for your Template, and add an optional description. Once saved, your new template will be added to the Template Drop down list on the Translations Workspace where it can be reused.

  5. Now, continue down each row until all fields are correctly mapped.

    • Advanced Tip: When you are finished translating all the values for a field, click the small triangle next to the Bolded Field Name to close that section. You can click the triangle again to re-open the section.

  1. When you are done mapping the fields, click the Next button to continue to the Validations Page.

    • The Next button will be grayed out and unusable until you have mapped all 8 Critical Fields.
